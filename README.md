# Copenhagen NLP Symposium 2026

Static site for the 2026 Copenhagen NLP Symposium.

## Publishing at cphnlp.github.io

This repository is ready for GitHub Pages. To publish it at the same address used in 2025:

1. Push this project to the `cphnlp/cphnlp.github.io` GitHub repository (the special user/organisation Pages repository).
2. In **Settings → Pages**, choose **Deploy from a branch**, then select the branch containing this site and the `/(root)` folder.
3. GitHub will serve the new `index.html` at `https://cphnlp.github.io/`.

The **Previous editions** link uses an archived June 2025 snapshot, so it will continue to point to last year's site after the root Pages address is updated. Before publishing, replace any 2026 “to be announced” content and update the contact email if needed.
